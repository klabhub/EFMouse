# EFMouse: a toolbox to model electric fields in the mouse brain
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.14777232.svg)](https://doi.org/10.5281/zenodo.14777232) ![License](https://img.shields.io/badge/License-MIT-yellow.svg)

<img width="300" height="350" alt="EFMouse example image" align ="right" src="https://github.com/user-attachments/assets/94a7dc36-9060-4389-8e5d-32672d794e2f" />

The [EFMouse.m](https://github.com/klabhub/EFMouse/blob/main/EFMouse.m) Matlab class models electric fields generated by current stimulation in
the mouse. This toolbox uses some of the same approaches as [ROAST](https://github.com/andypotatohy/roast), which models electric fields in the human head. 

For details see [Sanchez-Romero et al. (2025) PLOS Comput. Biol.](https://doi.org/10.1371/journal.pcbi.1013471) <br /> 

Run the different Matlab tutorials `montage_*.mlx` to reproduce results in Sanchez-Romero et al.<br />
You can visualize (not interact with) the tutorials directly here [montage_1xBack.html](https://klabhub.github.io/EFMouse/montage_1xBack.html), [montage_1x4.hmtl](https://klabhub.github.io/EFMouse/montage_1x4.html), [montage_4xBack_craniotomy.html](https://klabhub.github.io/EFMouse/montage_4xBack_craniotomy.html), [montage_1x1_craniotomy.hmtl](https://klabhub.github.io/EFMouse/montage_1x1_craniotomy.html) and [montage_1x1_craniotomy_skinBone-csf.html](https://klabhub.github.io/EFMouse/montage_1x1_craniotomy_skinBone-csf.html)

## Installation and dependencies
Requires MATLAB/2023a or later versions, and the Partial Differential Equation Toolbox. 

Clone the repository from github `git clone https://github.com/klabhub/EFMouse.git`

Analyzing results with reference to the Allen mouse atlas requires the [FSL 
package](https://fsl.fmrib.ox.ac.uk/fsl/docs/#/) 6.0.7 or later versions. (FSL applies a transformation to the simulation results to map them to the Allen atlas.)

## Tutorial
To get started, open one of the `montage_*.mlx` files in Matlab and follow the compute pipeline, the analysis suggestions, 
and for additional options look up the help for each of the functions used in the tutorial.
